## How it runs

`main.ts` (Node 22, standard library only) copies the finished front page, `entry.png` (1024×1024, under 1 MiB), to the output folder:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program draws nothing at run time, so both grading runs produce the exact same bytes.
